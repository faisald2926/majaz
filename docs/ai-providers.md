# إعداد مسودات GPT وClaude — 23 أكتوبر 2026

المساعدة اختيارية في مساحة ولي الأمر البالغ لإعداد نصوص تعليمية يختارها ويراجعها. لا توجد محادثة ذكاء اصطناعي للطفل، ولا إرسال آلي لطلباته أو عمره أو مكتبة الأسرة أو رموز الدخول. مفتاحا المزودين مستقلان ويستعملهما الخادم فقط.

## الإعداد المحلي

انسخ `.env.example` إلى `.env` فقط إن لم يكن الملف موجودًا؛ احتفظ بأي إعدادات خاصة موجودة. أدخل مفاتيح حسابات API الخاصة بك في الملف المحلي، ثم أعد تشغيل الخادم:

```dotenv
MAJAZ_AI_ENABLED=true
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-luna
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-sonnet-5-5
```

القيم الفارغة لا تفعّل المزود. يمكن تشغيل أحدهما وحده أو كلاهما. `MAJAZ_AI_ENABLED=false` يوقف الإرسال لكليهما. يقرأ الخادم `.env` باستخدام Node.js عند تشغيل الملف الرئيسي؛ استيراد وحدة الخادم في الاختبارات لا يقرأ الملف. متغيرات البيئة الموجودة مسبقًا لها الأولوية. لا توجد مفاتيح فعلية في المستودع أو مثال الإعداد، ولا تُعرض قيمها عبر API أو المتصفح. لا تُحزم ملفات الإعداد الخاصة أو بيانات المكتبات في البناء.

النماذج الافتراضية موثقة في [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) و[Claude Sonnet 5.5](https://platform.claude.com/docs/en/models/sonnet-5-5/overview). يمكن تغييرها إلى نماذج متوافقة متاحة لحسابك؛ توفر النموذج وصحة المفتاح والفوترة لم تُختبر حيًا. لا يبدّل الخادم المزود أو النموذج تلقائيًا.

## تدفق المراجعة

1. يختار البالغ المزود ونصًا تعليميًا لديه حق استعماله، ويؤكد الموافقة وخلو النص من البيانات الشخصية.
2. تُرسل المادة المختارة فقط إلى المزود، ويعرض المحرر معاينة مسودة غير معتمدة.
3. يختار البالغ استخدام المسودة واستبدال بطاقات المحرر. إغلاق النافذة أو تغيير النص أو المزود يمنع تطبيق نتيجة الطلب السابق.
4. يحفظها في المكتبة كمادة تحتاج مراجعة؛ لا يحصل الطفل عليها حتى الاعتماد المعتاد لكل نسخة.

لا تنشر الاستجابة أو تصدر الموافقة أو تغيّر المكتبة من مسار `draft`. صلاحية الوالد مطلوبة خادميًا، وتبقى طلبات الطفل موضوعات يراجعها البالغ دون استدعاء خدمة خارجية.

## الضوابط والحدود

- OpenAI يستخدم Responses API و`text.format` مع JSON Schema، و`store:false`. هذه القيمة لا تعني اعتماد Zero Data Retention أو غياب كل احتفاظ لدى المزود.
- Claude يستخدم Messages API و`output_config.format` وفق وثائقه الرسمية.
- الوجهتان ثابتتان في الكود، مع رفض تحويلات HTTP، وحد استجابة 256 KiB، ومهلة 20 ثانية تشمل الاستجابة وجسمها. يجري تحقق محلي من وجود 1–20 بطاقة وعناوين ونصوص غير فارغة وحدود الأحرف، ورفض الحقول الإضافية ومنها الموافقات.
- رد ناقص أو رفض سلامة أو خطأ في التهيئة أو تجاوز المهلة لا ينتج مادة محفوظة. رسائل أخطاء المزود الخام لا تعاد إلى المتصفح. لا إعادة تلقائية أو تبديل خدمة قد يسبب إرسالًا أو تكلفة إضافيين دون اختيار البالغ.
- خمس محاولات في الدقيقة لكل مكتبة وطلب جارٍ واحد. هذا ضبط محلي، وليس نظام ميزانية أو منع إساءة استخدام صالحًا لخدمة عامة متعددة الحسابات.
- الإقرار بخلو المادة من البيانات الشخصية تأكيد من المستخدم؛ لا يوجد كاشف شامل للبيانات الشخصية أو تحقق عمر وهوية. لا تدخل بيانات طفل أو شخص حقيقي في هذا التدفق. المحتوى الناتج يحتاج قراءة بشرية، ولا يُضمن أنه صحيح أو مناسب.

[إرشادات OpenAI لمن هم دون 18](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance) تطلب ضمانات إضافية وتحظر معالجة البيانات الشخصية لمن دون 13 أو سن الموافقة المطبق دون تفعيل Zero Data Retention أولًا. [إرشادات Anthropic للمنظمات التي تخدم القاصرين](https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors) تطلب ضمانات مناسبة للفئة المستفيدة. قصر إعداد المسودات على الوالد لا يمنح شهادة امتثال للمنصة؛ يلزم تقييم مستقل قبل إطلاق خدمة عامة أو إشراك أطفال حقيقيين.

Gemini يبقى معطّلًا في التطبيق، والمهايئ السابق محفوظ كأداة اختبار تاريخية معزولة. تقرير 22 أكتوبر يصف المرحلة السابقة؛ هذه الإضافة لاحقة له.

## مصادر التنفيذ والتحقق

- [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
- [Claude Structured Outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs)
- `test/ai.test.mjs`: استجابات محقونة وخادم localhost حقيقي لفحص الصلاحيات وعدم الحفظ وحصة الطلبات؛ لا اتصالات حية بالمزودين.
- `scripts/browser-ai-qa.mjs`: Chromium وواجهات فعلية، مع مزودين محاكيين ومواد مؤلفة، للتحقق من المعاينة وعدم ظهور المحتوى قبل الاعتماد.

لا مفاتيح قدمها المشارك في هذه المرحلة، ولا نتيجة اتصال حي أو أثر أسري مقاس. يظل الموقع نموذجًا محليًا.

نتيجة التحقق: 30 اختبار مصدر ناجحًا، منها 8 حالات جديدة لربط المزودين؛ و5 فحوص واجهة للمزودين بالمحاكاة، مع بقاء رحلة الاستخدام ذات 10 فحوص واختبارات تأخر الردود السبعة ناجحة. [سجل التحقق](ai-provider-checks.json) يوضح نطاق المحاكاة؛ لا يثبت صلاحية مفتاح حقيقي أو توفر النموذج لحساب المستخدم.
