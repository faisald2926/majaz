# تقرير تنفيذ مجاز

تاريخ التنفيذ والتحقق: 8 أكتوبر 2026. المنفذ GPT 6.1 Sol في مستودع مستقل وفرع `prototype`. لا تجربة مع أطفال أو أسر حقيقية، ولا إرسال استبانة، ولا نتائج اجتماعية أو نسب حماية مصطنعة. المواد التعليمية وfixtures الاختبارات مؤلفة. لا مفتاح خدمة مقدم، ولا اتصال Gemini حي.

## النطاق المنفذ

موقع عربي RTL كامل بصفحة تعريفية ومساحة إدارة للوالد ومساحة استكشاف للطفل. تشمل الوظائف إنشاء مكتبة خاصة، إدخال مصادر وبطاقات، مراجعة كل بطاقة وعنوانها وسياقها، اعتماد نسخة، إبطالها، تحرير النصوص والترتيب وإظهار الفرق السابق والحالي، ضبط عمر الطفل والسياسة، روابط دور مستقلة، طلب موضوع للوالد، بحث عربي وقراءة وحفظ وطباعة وتصدير المعتمد، وتصدير واستيراد نصوص المكتبة دون نقل الموافقات أو الرموز.

Node.js HTTP ومكتباته القياسية فقط؛ لا حزم تشغيل ولا npm install. نسخة Node الفعلية أثناء التحقق `v24.19.0`، والحد المطلوب `>=22`. الخادم المحلي افتراضيًا `127.0.0.1:3173`. التخزين JSON محلي خارج Git؛ نسخ العمليات تعمل على clone ثم يُحفظ snapshot مرشح قبل نشره في الذاكرة. فشل الحفظ يترك الحالة الحالية ورمز الطفل السابق كما هما. ملفات البناء تستبعد `data/` و`.env` و`.git` وتشمل الشيفرة والاختبارات والوثائق، مع manifest لتجزئات ملفات الحزمة.

| `docs/transaction-red.txt` | 500 عند forced disk failure لكن بحث الطفل أعاد البطاقة المعتمدة | regression حقيقي قبل إصلاح publish-after-save؛ بعده لم تعد حالة فاشلة تظهر أو تدور صلاحياتها |
| `docs/validation-red.txt` | 2 فشل و1 نجاح | مدخلات null لم تكن ترفض ب400، وسياق المصدر السابق غير محفوظ؛ عولجا |
| `docs/test-green.txt` | 19 اختبارًا، 19 نجاحًا، صفر فشل | محرك + HTTP حقيقي + Gemini HTTP mock معلن + persistence regression + validation |
| `docs/build-green.txt` | بناء بلا اعتماد تشغيل وفحص syntax، exit 0 | الحزمة المنسوخة قابلة للتشغيل، ولا تنسخ أسرارًا أو بيانات مكتبات |
| `docs/browser-evidence.json` | 10 checks، صفر page errors | Chromium حقيقي، واعتماد يدوي وقراءة وحفظ وإبطال وطلب موضوع ومراجعة فرق و390px |

الأوامر الفعلية: `npm start` و`npm test` و`npm run build` و`npm run verify`، مع وضع Node المضمن في PATH. استُعملت صلاحية تشغيل خارج الرمل للاختبارات التي تتصل بـ127.0.0.1 بعدما ثبت أن الرمل يمنعها؛ لا حزم ثبتت ولا اتصالات لمستخدمين أو أطفال. `node scripts/browser-qa.mjs` يستخدم Playwright المتاح مسبقًا في بيئة العمل، وهو أداة تحقق اختيارية وليس اعتماد تشغيل. أداة mutation `node scripts/mutation-evidence.mjs` أنشأت fixture مؤقتًا معزولًا وحذفته بعد رصد الفشل.

## ضمانات تقنية محددة

- الفلترة خادمية قبل البحث والتصدير: الطفل لا يتلقى أسماء المصادر غير المعتمدة أو عناوينها أو مقتطفاتها أو تجزئات الموافقات أو أعداد corpus الخاص. لا تطابق يعيد `cards: []` فقط. استجابة حالة الاتصال تعطي معرف تحديث عشوائيًا دون عداد تعديل.
- اختبار صلاحية الدور يستخدم رموزًا عشوائية 256-bit مستقلة وتجزئات محفوظة ومقارنة ثابتة التوقيت. تغيير role في الصفحة أو رمز مزور لا يتيح قراءة أو تعديل أو اعتماد الوالد. المسارات غير المصرح بها ترد 403.
- بصمة الموافقة تضم النص والعنوان والعمر والسياسة وعنوان المصدر ونمطه. السياق المترابط يضم جميع المقاطع وترتيبها. بطاقات مستقلة لا تحافظ على موافقات غير متغيرة إلا بتصريح الوالد باكتمال معناها؛ تغيير سياقها العام يعيدها للمراجعة.
- القراءة والحفظ يتطلبان معرف النسخة الحالية، والنسخة القديمة أو الموافقة المبطلة ترد 409. المستورد نصوص فقط، وكل بطاقاته غير معتمدة. إعدادات العمر والسياسة لا تؤخذ من الملف.
- فحوص Origin وcontent type وحدود الأحجام وعنوان Host وسياسة CSP موجودة. النص والعناوين والبحث تُعامل نصًا في الواجهة. لا fetch تعسفي لروابط المستخدم ولا iframe أو فيديو أو تنفيذ HTML.
- فحص الطفل كل 5 ثوانٍ خلال نشاط الصفحة يحجب المحتوى الملغى، وعند فشل الاتصال يوقف العرض. إخفاء الصفحة يحجب المحتوى؛ إظهارها يجبر تحديثًا حتى لو بقي revision كما هو. اختبار lifecycle استخدم أحداث visibility محاكاة داخل Chromium، والمعالج وHTTP حقيقيان؛ لا يُوصف بأنه اختبار سلوك مؤقت كل متصفح.
- مراجعة Astra كشفت خطر نشر التعديل قبل نجاح الحفظ، وخطر البقاء في paused screen بعد إظهار الصفحة. أُضيف regression للأول والتحقق المرئي للثاني، ثم أعيد التحقق.

## Gemini ومصادر المقارنة

المهايئ REST خادمي إلى Google `generateContent`، والمفتاح متغير البيئة `GEMINI_API_KEY` فقط. النموذج قابل للضبط عبر `GEMINI_MODEL` وافتراضيًا `gemini-3.5-flash-lite`، وقد ظهر في [قائمة النماذج الرسمية](https://ai.google.dev/gemini-api/docs/models) التي روجعت أثناء التنفيذ في 8 أكتوبر 2026. مخطط استجابة JSON ومهلة 15 ثانية والتحقق الصارم محليًا؛ [مرجع structured output](https://ai.google.dev/gemini-api/docs/structured-output). موافقة صريحة على إرسال النص المختار، ولا موافقة محتوى تلقائية أو chat طفل حر. نجاح mock يختبر بنية المهايئ؛ لا يثبت عمل مفتاح حقيقي أو الاستجابة الحية أو التكلفة أو توفر حساب.

وثائق البدائل المقروءة: [YouTube Kids الموافق عليه فقط](https://support.google.com/youtubekids/answer/6172308)، [Sprout Browser وحدوده](https://sproutbrowser.com/safety)، [SingleFile](https://github.com/gildas-lormeau/SingleFile)، ومستندات PDF بديل بسيط. لا تثبيت منافسين ولا تجربة سوقية. الفرق المحدود هو اعتماد بطاقة نصية وسياق نسخة وبحث خادمي في المعتمد؛ الموافقة المسبقة نفسها موجودة لدى بدائل حقيقية. لا ادعاء جدة مطلقة أو أهلية ملكية فكرية. جميع حقوق الشيفرة الأصلية محفوظة؛ package خاص وغير مرخص للانتشار العام.

## الصور والمخططات

7 صور فعلية: landing-desktop، parent-desktop، child-desktop، parent-review، parent-mobile، child-mobile، child-empty-mobile. لا صور واجهة مُولدة بالذكاء الاصطناعي ولا بيانات مشاركين فيها. فُحصت بصريًا صفحات البداية والوالد والطفل على الهاتف. خمسة Mermaid في README وثلاثة SVG مستقلة في `docs/diagrams/`.

## حدود ما تم إثباته

الحماية داخل هذه البوابة على الجهاز المحلي. لا حجب للإنترنت أو تطبيقات الهاتف ولا مراقبة للاستخدام ولا تصنيف آلي لسلامة النص ولا التحقق من فهم الطفل. الموافقة البشرية يمكن أن تكون خاطئة، وتصريح استقلال البطاقة ليس حكمًا لغويًا آليًا. تشغيل حساب نظام التشغيل أو نافذة الوالد في يد الطفل أو مشاركة رابط الوالد يتجاوز حدود أدوار الموقع. البيانات غير مشفرة على القرص. لا يستطيع الخادم سحب بطاقة سبق نسخها أو تصديرها أو تصويرها أو قراءتها. مؤقتات الخلفية قد تتأخر. لا تحقق هوية أو صلاحيات متعددة لأفراد حقيقيين أو مزامنة سحابية أو استعادة روابط أو واجهة لأجهزة أخرى. الخادم نموذج محلي، لا حزمة نشر إنترنت محصنة. سهولة الاستخدام والأثر الأسري وملاءمة الأعمار لم تختبر ميدانيًا.
